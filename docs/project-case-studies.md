# Project Case Studies

Short technical notes for the portfolio projects. The public UI shows the polished cards; this file gives a recruiter or client a faster engineering read.

## DreamTune

- **Preview:** `client/public/assets/dreamtune.png`
- **Live/API:** https://huggingface.co/spaces/dreamtune7/dreamtune-api
- **Stack:** React, Vite, Tailwind, Node.js, Express, PostgreSQL, Capacitor
- **Product idea:** mobile-friendly music platform with playlist synchronization, automated audio sourcing direction, offline playback direction, and Android-style interaction patterns.
- **Technical signal:** fullstack flow, API-driven data, external music-source integration direction, and a product UI that thinks beyond a static playlist screen.

## GymEngine

- **Preview:** `client/public/assets/gymengine.png`
- **GitHub:** https://github.com/sashik117/GymEngine
- **Stack:** Flutter, Dart, NestJS, TypeScript, SQLite, Node.js
- **Product idea:** strength training companion focused on fast workout logging, structured routines, offline-ready storage, and a phone-first flow for real gym usage.
- **Technical signal:** mobile UX decisions, local persistence, backend planning, and a use case where speed and low-friction interaction matter.

## NutriAI

- **Preview:** `client/public/assets/nutriai.png`
- **GitHub:** https://github.com/sashik117/NutriAI
- **Stack:** React, Vite, Tailwind, Node.js, Express, PostgreSQL, Gemini AI
- **Product idea:** smart nutrition platform with AI-assisted meal analysis, calorie tracking, gamified rewards, and structured health data.
- **Technical signal:** AI integration, database-backed user flow, validation-heavy product logic, and a dashboard-style interface with useful states.

## PajamaTalk

- **Preview:** `client/public/assets/pajamatalk.svg`

## DrivePrep / PDRPrep

- **Preview:** `client/public/assets/driveprep.svg`
- **GitHub:** https://github.com/sashik117/pdr_prep
- **Stack:** React, Vite, Tailwind, FastAPI, Python, PostgreSQL, Framer Motion
- **Product idea:** Ukrainian driving theory exam platform with official-style simulations, progress analytics, battles, theory content, and premium-tier architecture.

## Menu Portal

- **Preview:** `client/public/assets/menu-portal.svg`
- **Stack:** PHP, Laravel, Blade, MySQL, CRUD, Admin Panel
